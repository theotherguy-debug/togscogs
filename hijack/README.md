# Hijack — Network Tracing Simulator

A cybersecurity hacking minigame simulation where operatives bypass firewalls, crack encryption layers, and compete on a server-wide hacker scoreboard. Features timed intrusion puzzles and ANSI-styled terminal interfaces.

---

## 🚀 Setup & Installation

1. Load the cog:
   ```
   [p]load hijack
   ```
2. No additional configuration required — users can start hacking immediately.

---

## ⌨️ User Commands

| Command | Description |
|:---|:---|
| `[p]hijack` | Trigger a hacking intrusion session. Solve timed puzzles to breach the system. |
| `[p]rankings` | Show the server's top terminal hijackers on the scoreboard. |

---

## 🛠️ Admin Controls (via `/root` → Hacking UI)

| Button | Description |
|:---|:---|
| **Toggle Firewall Lockdown** | Enable/disable the global firewall lockdown state. When active, breach attempts are blocked. |

---

## 🎮 How It Works

1. Run `[p]hijack` to begin an intrusion session
2. The bot presents a series of timed cybersecurity challenges
3. Solve them correctly to advance through firewall layers
4. Your score is tracked on the server leaderboard (`[p]rankings`)
